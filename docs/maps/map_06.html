Detailed base map of the UCSB main campus using the visualization style of Map 1

Rendered Map Plate

Technical Summary

  • Objective: Provide a focused, high-detail coastal base map of UCSB’s main campus, designed using the visualization style of Map 1 and optimized to sit as the bottom hero panel of the composite Map 7 atlas plate.
  • Key Packages: terra, sf, ggplot2, dplyr
  • Data Sources:
    • Campus DEM (source_data/campus_DEM.tif)
    • Campus bathymetry (output_data/campus_bath_epsg2874.tif)
    • Campus hillshade (source_data/campus_hillshade.tif)
    • Campus buildings footprint (source_data/campus_buildings/Campus_Buildings.shp)
    • Isla Vista building structures (source_data/iv_buildings/iv_buildings/CA_Structures_ExportFeatures.shp)
    • Bike path centerlines (source_data/icm_bikes/bike_paths/bikelanescollapsedv8.shp)
    • NCOS Shorebird Foraging Habitat polygons (source_data/NCOS_Shorebird_Foraging_Habitat/)
    • NCOS Multi-use Trails (source_data/ncos_trails/ncos_multiuse_trails.geojson)
  • Aspect Ratio: 12 inches wide x 4 inches tall (3600 x 1200 px at 300 ppi) matching the Map 7 row 2 hero slot.

Step-by-Step Cartographic Workflow & Intermediate Outputs

The script scripts/map_06.r tightens the geographic extents of Map 1 to create an ultra-wide panoramic foundation map.

Step 1: Ingesting Vectors & Harmonizing Projections

The vector layers for buildings, bikeways, habitats, and Isla Vista structures are reprojected using st_transform to match the native projection of campus_DEM.tif (EPSG:2874 - NAD83 / California zone 5 (ftUS)).

# Align vector layers to DEM CRS
campus_projection <- crs(campus_DEM)
campus_bath <- project(campus_bath, campus_projection)
campus_hillshade <- project(campus_hillshade, campus_projection)
buildings <- st_transform(buildings, campus_projection)
bikeways <- st_transform(bikeways, campus_projection)
habitat <- st_transform(habitat, campus_projection)

Step 2: Intermediate Plot — Vector Alignment & Minimalist Graticule

Before adding the heavy raster stack, the script validates vector positions using a test plot styled with the custom rAtlas_theme.

# Intermediate vector layer test plot
ggplot() +
  geom_sf(data = habitat) +
  geom_sf(data = buildings) +
  geom_sf(data = iv_buildings) +
  geom_sf(data = bikeways) +
  theme(rAtlas_theme) +
  coord_sf()

Step 3: Cropping Rasters to Main Campus Extents & Map 1 Visualization

The digital elevation model, bathymetry, and hillshade rasters are tightly cropped to the main campus bounding extent:

# Crop all 3 raster inputs to the main campus bounding extent
main_campus_extent <- ext(5998500, 6008500, 1973500, 1982500)
campus_DEM_crop <- crop(campus_DEM, main_campus_extent)
campus_bath_crop <- crop(campus_bath, main_campus_extent)
campus_hillshade_crop <- crop(campus_hillshade, main_campus_extent)

Finally, the raster surfaces and vector layers are composited into a panoramic layout matching the visualization style of Map 1:

# Render main campus base map with Map 1 styling
final_map6 <- ggplot() +
  geom_raster(data = campus_DEM_df, aes(x = x, y = y, fill = elevation)) +
  geom_raster(data = campus_hillshade_df, aes(x = x, y = y, alpha = hillshade), show.legend = FALSE) +
  geom_raster(data = campus_bath_df, aes(x = x, y = y, fill = bathymetry)) +
  scale_fill_viridis_c(na.value = "NA", guide = guide_legend("bathymetry / elevation (US ft)")) +
  scale_alpha(range = c(0.05, 0.4), guide = "none") +
  geom_sf(data = iv_buildings, color = alpha("light gray", 0.15), fill = NA) +
  geom_sf(data = buildings, color = "pink", fill = alpha("pink", 0.3)) +
  geom_sf(data = habitat, color = alpha("darkorchid1", 0.3), fill = alpha("darkorchid1", 0.1)) +
  geom_sf(data = bikeways, color = "#00abff", linewidth = 0.8) +
  geom_sf(data = ncos_trails, color = "#00abff", linewidth = 0.8) +
  coord_sf(
    xlim = c(main_campus_extent$xmin, main_campus_extent$xmax),
    ylim = c(main_campus_extent$ymin, main_campus_extent$ymax),
    expand = FALSE
  ) +
  labs(
    title = "Map 6: UCSB Main Campus",
    subtitle = "Main campus buildings, environs, bikepaths",
    caption = "rAtlas Map 6"
  ) +
  rAtlas_theme +
  theme(
    plot.title = element_text(size = 18, face = "bold", hjust = 0),
    plot.subtitle = element_text(size = 13, hjust = 0),
    legend.position = "bottom"
  )

# make our ggtitles automagically #######
gg_labelmaker <- function(plot_num) {
  gg_title <- c("Map:", current_sheet, " ggplot:", plot_num)
  plot_text <- paste(gg_title, collapse = " ")
  print(plot_text)
  current_ggplot <<- plot_num
  return(plot_text)
}
