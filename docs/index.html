UCSB R-Atlas

A geospatial R example atlas of the UC Santa Barbara campus

Welcome to the UCSB R-Atlas, a collection of publication-quality cartographic plates and geospatial workflows showcasing the University of California, Santa Barbara campus.

This project uses local UCSB examples applied to all steps of the Carpentries’ Introduction to Geospatial Raster and Vector Data with R curriculum.

Atlas Map Plates

Explore the 12 atlas maps and spatial analyses:

Map 1: Campus Overview

A wide view of the campus featuring bathymetry, topography, hillshade, bike paths, buildings, and lagoon habitats.

Map 2: Trees & Water

A stylized thematic map visualizing campus tree species and heights alongside water features and bikeways.

Map 3: Western US

Regional locator inset showing elevation across the Western United States.

Map 4: The Bight of California

Sub-regional locator map focusing on the Southern California Bight, Channel Islands, and campus extent.

Map 5: Extended Campus

Detailed locator view of the greater campus area showing topography, bathymetry, and hillshading.

Map 6: UCSB & Environs

Wide base map providing context for UCSB, Isla Vista, and surrounding coastal environments.

Map 7: Atlas Page Layout

Composite multi-inset atlas plate combining Maps 3, 4, 5, and 6 assembled using magick.

Map 8: Satellite Remote Sensing

PlanetScope multi-spectral satellite imagery comparing campus across seasons.

Map 9: Vernal Pools Analysis

Topographic depression analysis using DEMs to identify campus vernal pools (in design).

Map 10: Paths & Creeks

Vector intersection analysis locating where campus bike paths cross local waterways and creeks.

Map 10.5: Data Provenance & NCOS

Investigating data blind spots: why the restored NCOS trail and Devereux Creek bridge were missing in the 2016 dataset.

Map 11: Dibblee Geology

Georeferencing, quadrangle mosaicking, and AOI cropping for the historic Dibblee geologic map.

Map 12: 12-Month NDVI Stack

Time-series raster analysis tracking vegetation phenology over a full calendar year.

Getting Started

  1. Clone the repository:

    git clone https://github.com/UCSBCarpentry/ucsb-ratlas.git
cd ucsb-ratlas

  2. Download source data: Run scripts/data_prep_new.r (or scripts/data_prep.r) to download the required dataset archive from Google Drive and unzip into source_data/.

  3. Run map scripts: Execute scripts/run_every_map.r to render all atlas plates into images/ and final_output/.

  4. Learn more:

    • Explore our Data Dictionary for layers and CRS definitions.
    • Read our Progress Log for developmental notes.
    • Visit UCSB Carpentry.

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/UCSBCarpentry/ucsb-ratlas.git
   cd ucsb-ratlas
   ```

2. **Download source data:**
   Run `scripts/data_prep_new.r` (or `scripts/data_prep.r`) to download the required dataset archive from Google Drive and unzip into `source_data/`.

3. **Run map scripts:**
   Execute `scripts/run_every_map.r` to render all atlas plates into `images/` and `final_output/`.

4. **Learn more:**
   - Explore our [Data Dictionary](datadictionary.qmd) for layers and CRS definitions.
   - Read our [Progress Log](progress.qmd) for developmental notes.
   - Visit [UCSB Carpentry](https://ucsbcarpentry.github.io).
