Data Dictionary

Alphabetical catalog of source data and complete map-by-map file dependencies

This data dictionary provides an authoritative inventory of all geospatial datasets in the UCSB R-Atlas project. It is organized in two parts: first, a comprehensive alphabetical catalog of all raw datasets located in source_data/; second, a detailed map-by-map pipeline listing all input source layers, intermediately created files, and final published figures.

Part 1: Alphabetical Catalog of source_data

Below is an alphabetical inventory of all source layers located in source_data/, specifying their data types, coordinate reference systems (CRS), provenance, and the maps or tutorial episodes in which they are used.

1. 07gGoleta/ (Dibblee Quadrangle DF-07)

  • Primary File: source_data/07gGoleta/DB0007.tif
  • Format: Scanned RGB GeoTIFF raster with internal world file / control points (.aux, .txt).
  • Original CRS: Unprojected scanned raster (rectified to California State Plane Zone 5 / NAD27 via Ground Control Points).
  • Coverage: USGS Goleta 7.5-minute quadrangle, Santa Barbara County, CA.
  • Description: Thomas W. Dibblee, Jr. Geologic Map of the Goleta Quadrangle (Dibblee Foundation Map DF-07, 1987). Captures local bedrock, fault lines (More Ranch Fault), and surficial Quaternary alluvial formations across the eastern portion of UCSB and Goleta Slough.
  • Used In: Map 11, Episode 11.

2. 09gDosPueblos/ (Dibblee Quadrangle DF-09)

  • Primary File: source_data/09gDosPueblos/DB0009.tif
  • Format: Scanned RGB GeoTIFF raster with internal GCP coordinate control.
  • Original CRS: Unprojected scanned raster (rectified to California State Plane Zone 5 / NAD27).
  • Coverage: USGS Dos Pueblos Canyon 7.5-minute quadrangle, Santa Barbara County, CA.
  • Description: Thomas W. Dibblee, Jr. Geologic Map of the Dos Pueblos Canyon Quadrangle (Dibblee Foundation Map DF-09, 1987). Covers western campus, Coal Oil Point Reserve, Devereux Slough, and western Goleta.
  • Used In: Map 11.

3. 10km_grid_wgs84/

  • Primary File: source_data/10km_grid_wgs84/10km_grid_wgs84.shp
  • Format: Vector Polygon Shapefile (.shp, .dbf, .prj, .shx).
  • CRS: WGS 84 (EPSG:4326).
  • Coverage: Regional Southern California.
  • Description: A regular 10-kilometer tessellation grid used for spatial aggregation exercises, spatial binning, and cartographic graticule development.
  • Used In: Tutorial exercises and spatial modeling modules.

4. 16gSolvangGaviota/

  • Primary File: source_data/16gSolvangGaviota/
  • Format: Directory placeholder.
  • Description: Historical quadrangle archive reference directory for northern Dibblee geologic map sheets (Solvang/Gaviota DF-16).
  • Used In: Map 11 fallback checks.

5. cali.geojson

  • Primary File: source_data/cali.geojson
  • Format: Vector Polygon GeoJSON.
  • CRS: WGS 84 (EPSG:4326).
  • Coverage: Bounding coordinates for California.
  • Description: Simplified boundary outline of the state of California used for rapid sub-setting, clipping extents, and spatial mask tests.
  • Used In: Early vector processing episodes.

6. cali_overview.geojson

  • Primary File: source_data/cali_overview.geojson
  • Format: Vector Polygon GeoJSON.
  • CRS: WGS 84 (EPSG:4326) ([-126.51°W, 31.23°N] to [-111.49°W, 44.42°N]).
  • Coverage: Western United States and Eastern Pacific Coast.
  • Description: Regional bounding box used to clip the global hillshade and continental DEM down to the Pacific Coast and Western US regional frame.
  • Used In: Map 3 (Western US Inset).

7. california_boundary.geojson

  • Primary File: source_data/california_boundary.geojson
  • Format: Vector MultiPolygon GeoJSON.
  • CRS: WGS 84 (EPSG:4326).
  • Coverage: State of California terrestrial boundaries.
  • Description: High-fidelity cartographic perimeter of the California state boundary, used to draw a clean border outline separating land from ocean in regional overviews.
  • Used In: Map 3.

8. california_streams/

  • Primary Files:
    • source_data/california_streams/California_Streams.shp
    • source_data/california_streams/streams_crop.shp
  • Format: Vector LineString Shapefile.
  • CRS: Projected CRS: California Teale Albers (NAD83 / EPSG:3310).
  • Coverage: State of California stream and river hydrographic network (USGS National Hydrography Dataset).
  • Description: Linear waterway features including Devereux Creek, Goleta Slough channels, Carneros Creek, and coastal drainage networks. streams_crop.shp is a pre-cropped sub-selection covering the Goleta basin.
  • Used In: Map 2, Map 10, Map 10.5, Episode 6, Episode 8.

9. campus_buildings/

  • Primary File: source_data/campus_buildings/Campus_Buildings.shp
  • Format: Vector MultiPolygon Shapefile.
  • CRS: WGS 84 (EPSG:4326).
  • Coverage: UCSB Main Campus, Storke Campus, and West Campus ([-119.8847°W, 34.4066°N] to [-119.8397°W, 34.4251°N]).
  • Description: Official university building footprints compiled by the UCSB Interactive Campus Map (ICM) and harvested via ArcGIS Online (412 structures).
  • Used In: Map 1, Map 5, Map 6, Map 10, Episode 6, Episode 8.

10. campus_DEM.tif

  • Primary File: source_data/campus_DEM.tif
  • Format: Single-band Float32 GeoTIFF elevation raster.
  • CRS: NAD83(HARN) / California zone 5 (ftUS) (EPSG:2874).
  • Dimensions: 701 rows x 1,000 columns at 20 ft resolution.
  • Elevation Range: ~0 ft (sea level) to ~173 ft (campus bluffs and foothills).
  • Description: Digital Elevation Model covering UCSB main campus, West Campus, Isla Vista, and the Goleta Slough. Serves as the primary spatial reference and projection benchmark across local atlas maps.
  • Used In: Map 1, Map 3 (reference CRS), Map 4 (extent derivation), Map 5, Map 6, Map 9, Episodes 1–4.

11. campus_hillshade.tif

  • Primary File: source_data/campus_hillshade.tif
  • Format: Single-band 8-bit grayscale GeoTIFF raster.
  • CRS: NAD83(HARN) / California zone 5 (ftUS) (EPSG:2874).
  • Dimensions: 697 rows x 999 columns at 20 ft resolution.
  • Pixel Range: 0–255 (illumination angle 315° NW, 45° elevation).
  • Description: Analytical hillshade raster computed from campus_DEM.tif using terra::shade(). Provides three-dimensional relief rendering and depth perception when combined with semi-transparent elevation fills.
  • Used In: Map 1, Map 5, Map 6, Episode 2, Episode 4.

12. cirgis_1ft/

  • Primary File: source_data/cirgis_1ft/w_campus_1ft.tif
  • Format: 3-band 8-bit RGB GeoTIFF aerial orthophoto with pyramids (.ovr).
  • CRS: NAD83 / California zone 5 (ftUS) (EPSG:2229 / 2874).
  • Resolution: 1-foot per pixel ground sample distance.
  • Coverage: West Campus, Coal Oil Point Reserve, and North Campus Open Space.
  • Description: High-resolution orthophotography from the Channel Islands Regional GIS Collaborative (CIRGIS) 2020 flight. Used as ground truth for cross-validating the reconstructed Devereux Creek bridge and modern NCOS trail alignments.
  • Used In: Map 10.5 reference verification.

13. dem90_hf/ / ElevationintheW/

  • Primary File: source_data/dem90_hf/dem90_hf.tif
  • Format: Single-band Int16 GeoTIFF raster.
  • CRS: North America Albers Equal Area Conic (ESRI:102008).
  • Resolution: 90 meters per pixel.
  • Coverage: Western United States (Pacific Northwest to Mexican border, Rockies to Pacific Ocean).
  • Description: USGS / ScienceBase 90-meter Digital Elevation Model for the Western United States. Provides elevation data for regional continental insets.
  • Used In: Map 3, Map 4.

14. global_raster/ (Natural Earth Ocean Relief)

  • Primary File: source_data/global_raster/GRAY_HR_SR_OB.tif
  • Format: Single-band 8-bit grayscale GeoTIFF.
  • CRS: WGS 84 Geographic 2D (EPSG:4326).
  • Dimensions: 10,800 rows x 21,600 columns.
  • Description: Natural Earth high-resolution shaded relief and ocean water bottom raster (GRAY_HR_SR_OB). Displays ocean bathymetric texture, deep-water trenches, and continental shelves across the Pacific Ocean.
  • Used In: Map 3, Map 4.

15. greater_UCSB-campus-aoi.geojson

  • Primary File: source_data/greater_UCSB-campus-aoi.geojson
  • Format: Vector Polygon GeoJSON.
  • CRS: WGS 84 (EPSG:4326).
  • Coverage: Greater campus bounding envelope encompassing Goleta Slough, Ellwood Mesa, West Campus, and Storke Campus.
  • Description: Area of Interest (AOI) polygon defining the study boundary for multi-sheet mosaicking, historical quadrangle clipping, and satellite phenology analysis.
  • Used In: Map 11, Episode 11.

16. icm_bikes/ (Legacy 2016 ICM Bikeways)

  • Primary File: source_data/icm_bikes/bike_paths/bikelanescollapsedv8.shp
  • Format: Vector MultiLineString Shapefile.
  • CRS: NAD83 / California zone 5 (ftUS) (EPSG:2874).
  • Coverage: UCSB main campus, Isla Vista interfaces, and southern campus perimeter.
  • Description: Legacy university bicycle network centerlines digitized from the 2016–2017 UCSB Interactive Campus Map. Note that this dataset predates the 2018–2021 NCOS restoration and terminates at Whittier Drive.
  • Used In: Map 1, Map 2, Map 5, Map 6, Map 10, Map 10.5, Episodes 6, 8, 10.

17. iv_buildings/

  • CRS: WGS 84 (EPSG:4326).
  • Coverage: Unincorporated Isla Vista urban core adjacent to UCSB campus.
  • Description: Building structure polygons covering the private urban area of Isla Vista, used to provide neighborhood context without distracting from campus facilities.

Detailed Map Pipeline Specifications

Map 1: Campus Overview (scripts/map_01.r)

  • Objective: Produce a broad overview plate of the UCSB campus combining topography, ocean bathymetry, hillshading, bike path networks, and building footprints.
  • Source Inputs:
    • Elevation: source_data/campus_DEM.tif
    • Ocean Bathymetry: source_data/SB_bath.tif
    • Hillshade: source_data/campus_hillshade.tif
    • Built Infrastructure: source_data/campus_buildings/Campus_Buildings.shp
    • Urban Neighborhood: source_data/iv_buildings/iv_buildings/CA_Structures_ExportFeatures.shp
    • Active Bikeways: source_data/icm_bikes/bike_paths/bikelanescollapsedv8.shp
    • Modern Multi-Use Trails: source_data/ncos_trails/ncos_multiuse_trails.geojson
    • Protected Habitat: source_data/NCOS_Shorebird_Foraging_Habitat/NCOS_Shorebird_Foraging_Habitat.shp
  • Intermediately Saved Files:
    • output_data/campus_bath_epsg2874.tif: Coastal bathymetry reprojected to EPSG:2874 and cropped to match campus_DEM.
    • output_data/campus_bathotopo.tif: Merged continuous surface raster combining bathymetry and topography.
    • images/map1.1.png: Intermediate vector layer test.
    • images/map1.2.png & images/1.2.png: Layer transparency ordering tests.
    • images/map1.11.png: Pre-final annotated graphic.
  • Final Published Outputs:
    • final_output/map_01.png (16 x 9 in, 300 DPI overview map).

Map 2: Trees & Water (scripts/map_02.r)

  • Objective: Present a thematic visualization of the campus urban forest categorized by canopy type (Conifers, Deciduous, Eucalyptus) alongside waterways and coastal lines.
  • Source Inputs:
    • Campus Trees: source_data/Treekeeper_012116/DTK_012116.shp
    • Campus Bikeways: source_data/icm_bikes/bike_paths/bikelanescollapsedv8.shp
    • Regional Hydrography: source_data/california_streams/California_Streams.shp
    • Pacific Coastline: source_data/pacific_ocean-shapefile/3853-s3_2002_s3_reg_pacific_ocean_lines.shp
    • Urban Footprints: source_data/iv_buildings/iv_buildings/CA_Structures_ExportFeatures.shp
    • NCOS Trails: source_data/ncos_trails/ncos_multiuse_trails.geojson
  • Intermediately Saved Files:
    • images/map2_TreeHeight.png: Intermediate map classifying tree canopy heights.
    • images/map2_5_TreeSpecies.png: Intermediate plot categorizing the top 5 dominant species.
    • images/map2_TreeTypes.png: Intermediate 500 DPI rendering of broad canopy classifications.
  • Final Published Outputs:
    • final_output/map_02.png (16 x 9 in thematic plate).

Map 3: Western US (scripts/map_03.r)

  • Objective: Establish the continental scale for the Map 7 locator tryptic (Zoom 1), displaying the Pacific Coast of California against Western US topography.
  • Source Inputs:
    • Projection Benchmark: source_data/campus_DEM.tif
    • Ocean Shaded Relief: source_data/global_raster/GRAY_HR_SR_OB.tif
    • Continental DEM: source_data/dem90_hf/dem90_hf.tif

# Part 1: Alphabetical Catalog of `source_data`

Below is an alphabetical inventory of all source layers located in `source_data/`, specifying their data types, coordinate reference systems (CRS), provenance, and the maps or tutorial episodes in which they are used.

### 1. `07gGoleta/` (Dibblee Quadrangle DF-07)
* **Primary File:** `source_data/07gGoleta/DB0007.tif`
* **Format:** Scanned RGB GeoTIFF raster with internal world file / control points (`.aux`, `.txt`).
* **Original CRS:** Unprojected scanned raster (rectified to California State Plane Zone 5 / NAD27 via Ground Control Points).
* **Coverage:** USGS Goleta 7.5-minute quadrangle, Santa Barbara County, CA.
* **Description:** Thomas W. Dibblee, Jr. Geologic Map of the Goleta Quadrangle (Dibblee Foundation Map DF-07, 1987). Captures local bedrock, fault lines (More Ranch Fault), and surficial Quaternary alluvial formations across the eastern portion of UCSB and Goleta Slough.
